# Бот «Угадай слово»

Telegram-бот с игрой в угадайку слов по перемешанным буквам. Работает и в
личных чатах, и в группах. За каждое верное слово игрок получает 1 очко,
очки хранятся отдельно для каждого чата.

## Как это работает

- `/game` — бот перемешивает буквы случайного слова и присылает его.
- Любой участник чата пишет свою версию слова обычным сообщением.
- Первый, кто угадает — получает очко, и бот сразу загадывает следующее слово.
- `/stop` — остановить игру.
- `/score` — посмотреть свой счёт в этом чате.
- `/top` — таблица лидеров чата.

Очки хранятся в файле `scores.db` (SQLite), который создаётся автоматически
рядом с `bot.py`.

## Шаг 1. Создать бота через @BotFather

1. Открой в Telegram чат с [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot` (или используй уже существующего бота, которого ты
   настраивал на скриншоте — тогда просто возьми его токен через `/mybots` →
   выбрать бота → **API Token**).
3. Скопируй токен — длинную строку вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

### Важно для групп: отключи Privacy Mode

Чтобы бот видел сообщения-догадки всех участников группы (а не только
команды), отключи режим приватности:

1. В чате с @BotFather: `/mybots` → выбери своего бота.
2. **Bot Settings** → **Group Privacy** → **Turn off**.
3. Если бот уже был добавлен в группу — удали и добавь его заново после
   этого шага, чтобы изменения применились.

## Шаг 2. Установить зависимости

Нужен Python 3.10 или новее. В папке проекта выполни:

```bash
pip install -r requirements.txt
```

## Шаг 3. Указать токен

Самый простой способ — задать переменную окружения перед запуском:

**Windows (PowerShell):**
```powershell
$env:BOT_TOKEN="твой_токен_сюда"
python bot.py
```

**macOS / Linux:**
```bash
export BOT_TOKEN="твой_токен_сюда"
python3 bot.py
```

Либо просто открой `bot.py` и впиши токен прямо в строку:
```python
BOT_TOKEN = os.environ.get("BOT_TOKEN", "твой_токен_сюда")
```

## Шаг 4. Запустить

```bash
python3 bot.py
```

Если в консоли появилось «Бот запущен. Ожидание сообщений...» — всё готово.
Найди бота в Telegram, напиши `/start`, затем `/game`.

## Добавление в группу

1. Открой профиль бота в Telegram → **Добавить в группу/канал**.
2. Дай ему права обычного участника (админ не нужен, но убедись, что
   Privacy Mode отключён — см. выше).
3. В группе напиши `/game`, чтобы начать раунд.

## Как оставить бота работать постоянно (не только на своём компьютере)

Пока `python3 bot.py` запущен только у тебя на компьютере — бот работает
только пока открыт терминал и включен компьютер. Чтобы бот был доступен
24/7, его нужно разместить на сервере. Проще всего — бесплатные варианты:

- **Railway.app** или **Render.com**: залей эту папку как репозиторий на
  GitHub, подключи к сервису, укажи `BOT_TOKEN` в переменных окружения,
  команда запуска — `python bot.py`.
- **VPS** (например, Timeweb, Selectel, DigitalOcean): загрузи файлы на
  сервер, установи Python, зависимости, и запусти бота через `screen`,
  `tmux` или как systemd-сервис, чтобы он не останавливался при закрытии
  терминала.

## Как редактировать список слов

Открой `words.py` — там простой список строк `WORDS`. Можно добавлять,
удалять или менять слова как угодно (только строчными буквами, без
пробелов и дефисов).

## Возможные доработки на будущее
